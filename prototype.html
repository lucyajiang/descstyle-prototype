Step 1 of 3

Set up your description style

Before you take any images, choose how you'd like descriptions written. Nothing is selected yet — pick one option in each of the four groups. These become your default settings for every image, and you can change them at any point during the session.

These are the settings every new image starts from. Changing them here does not rewrite the description you were just listening to.

If you opened this by accident, choose “Go back without changing anything” at the bottom.
